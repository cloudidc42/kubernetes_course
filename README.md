# 🚀 หลักสูตร Kubernetes (K8s) ครบถ้วน ตั้งแต่พื้นฐานถึงระดับโลก

> หลักสูตรสอน Kubernetes แบบ Step-by-Step จากขั้นตอนที่ 1-1000 ครอบคลุมทุกหัวข้อที่จำเป็น

## 📚 เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ออกแบบมาเพื่อสอน Kubernetes ตั้งแต่ระดับ **เริ่มต้น** จนถึง **ระดับมืออาชีพ** และ **ระดับโลก** โดยแต่ละ Part มีเนื้อหาที่ใช้งานได้จริง 100% พร้อม Workshop และตัวอย่าง Code ที่ทดสอบแล้ว

## 🎯 เป้าหมายของหลักสูตร

- เข้าใจ Kubernetes Architecture อย่างลึกซึ้ง
- สามารถ Deploy แอปพลิเคชัน Production-Grade ได้
- รู้จัก Best Practices สำหรับ Security, Monitoring, และ CI/CD
- เตรียมสอบ CKA, CKAD, CKS Certification
- สร้าง Real-world Projects ที่ใช้งานได้จริง

## 🛠️ สิ่งที่ต้องเตรียม

### Hardware Requirements
- CPU: 4 cores ขึ้นไป
- RAM: 8GB ขึ้นไป (แนะนำ 16GB)
- Storage: 50GB ขึ้นไป

### Software Requirements
- OS: Ubuntu 20.04+ / macOS 12+ / Windows 10+ (with WSL2)
- Docker Desktop หรือ Docker Engine
- kubectl
- Minikube หรือ kind (สำหรับ Local Development)
